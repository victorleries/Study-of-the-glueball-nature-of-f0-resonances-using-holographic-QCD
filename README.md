# Study-of-the-glueball-nature-of-f0-resonances-using-holographic-QCD
All code used in my master thesis: Study of the glueball nature of f0 resonances using holographic QCD. Where I explored the possible glueball contribution to f0 resonances using Holographic QCD to obtain their Regge Trajectories.
All calculations are done using Wolfram's Mathematica, Jupyter notebooks are used to make the plots using matplotlib.pyplot.
